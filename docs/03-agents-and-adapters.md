# Agents and adapters

Besvelte uses agent adapters to run command line coding tools. Each adapter knows how to invoke an agent binary, pass flags, resume existing conversations, and parse output lines into structured events.

## Key features

* **Built-in adapters** - Support Claude Code, Codex, Gemini CLI, OpenCode, Shell, and Emgem.
* **Unified event stream** - Convert different JSON formats into standardized `AgentEvent` objects.
* **Conversation persistence** - Save agent session identifiers across turns.
* **Tool coordinate capture** - Extract screen coordinates when an agent clicks on a remote desktop.

## Supported agents

| Agent | Binary | Resume flag | Output format |
| --- | --- | --- | --- |
| `claude-code` | `claude` | `--resume <id>` | `stream-json` |
| `codex` | `codex` | `codex exec resume` | JSON line stream |
| `gemini` | `gemini` | `--resume <id>` | `stream-json` |
| `opencode` | `opencode` | `--session <id>` | JSON line stream |
| `shell` | `/bin/sh` | None | Raw stdout and stderr |
| `emgem` | `emgem` | `--session <id>` | Multimodal JSON |
| `fractalai` | `node` | `--session <id>` | Normalized JSON stream |

## The adapter interface

Every agent implements the `AgentAdapter` contract:

```ts
export interface TurnInput {
  readonly prompt: string;
  readonly sessionId?: string;
  readonly autoApprove: boolean;
  readonly allowTools?: readonly string[];
  readonly model?: string;
}

export interface AgentAdapter {
  readonly name: AgentName;
  readonly binary: string;
  readonly tested: boolean;
  argv(input: TurnInput): readonly string[];
  parse(line: string): readonly AgentEvent[];
}
```

## Normalised agent events

While the agent runs, its stdout lines are parsed into `AgentEvent` objects:

* **Session event** (`session`) - Captures the unique conversation ID generated by the agent.
* **Text event** (`text`) - Emits streamed explanation text for display in the chat thread.
* **Tool event** (`tool`) - Emits tool invocations with names, targets, and screen coordinates (`x`, `y`).
* **Result event** (`result`) - Signals completion with success status, final text, and dollar cost.
* **Standard error** (`stderr`) - Captures raw diagnostic messages.

## Writing a custom agent adapter

To add support for a new CLI agent, create a file in `src/agents/`:

```ts
import type { AgentAdapter, TurnInput } from "./types.js";
import { parseJson, str } from "./types.js";

export const myAgent: AgentAdapter = {
  name: "my-agent" as never,
  binary: "my-cli",
  tested: true,

  argv(input: TurnInput): readonly string[] {
    const args = ["my-cli", "--output", "json"];
    if (input.sessionId) {
      args.push("--continue", input.sessionId);
    }
    if (input.autoApprove) {
      args.push("--yes");
    }
    args.push(input.prompt);
    return args;
  },

  parse(line: string) {
    const json = parseJson(line);
    if (!json) return [];

    if (json.type === "message") {
      return [{ type: "text", text: String(json.content) }];
    }
    if (json.type === "done") {
      return [{ type: "result", ok: true, text: String(json.summary) }];
    }
    return [];
  }
};
```

Register the adapter in `src/agents/index.ts` to make it available to the CLI, SDK, and dashboard.
